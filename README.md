# Работа с PostgreSQL

Небольшое консольное Python-приложение для работы с PostgreSQL через `psycopg2`.
Оно создаёт таблицы пользователей и заказов, добавляет тестовые данные и
показывает сумму заказов по каждому пользователю.

## Требования

- Python 3.10 или новее.
- Запущенный сервер PostgreSQL и доступная база данных.
- Учётная запись PostgreSQL с правом подключения и создания/изменения таблиц.

## Установка и настройка

Из корневой папки проекта выполните:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
```

Откройте `.env` и задайте параметры своей базы:

```dotenv
PGHOST=localhost
PGPORT=5432
PGDATABASE=test
PGUSER=postgres
PGPASSWORD=
```

Если `PGPASSWORD` оставить пустым, программа запросит пароль в терминале
скрытым вводом. Значение `.env` не выводится программой. Не помещайте настоящий
пароль в `.env.example` и не публикуйте файл `.env`.

В проекте для подключения по умолчанию используются `localhost`, порт `5432`,
база `test` и пользователь `postgres`. Значения из окружения и `.env` имеют
приоритет над этими значениями.

## Запуск приложения

```bash
.venv/bin/python main.py
```

При запуске приложение подключается к PostgreSQL и создаёт таблицы, если их
ещё нет. Затем открывает меню:

1. **Создать таблицы** — создать `users` и `orders`, если они отсутствуют.
2. **Добавить тестовые данные** — добавить восемь тестовых пользователей и
   от 2 до 5 заказов для каждого.
3. **Показать сумму заказов по пользователям** — вывести суммы по убыванию.
4. **Выход** (`0`) — закрыть соединение и завершить программу.

В меню нужно вводить номер пункта. Неизвестный ввод не выполняет операцию:
программа сообщает об ошибочном пункте и показывает меню снова.

## Структура базы

`PostgresDriver.create_tables()` создаёт таблицы:

- `users`: `id` (автоинкрементный первичный ключ), `name` (обязательное имя),
  `age` (возраст, если задан, не может быть отрицательным).
- `orders`: `id` (автоинкрементный первичный ключ), `user_id` (обязательная
  ссылка на `users.id`), `amount` (обязательная сумма с точностью до двух
  знаков), `created_at` (время создания, по умолчанию текущее).

При удалении пользователя его заказы удаляются каскадно.

## Модули

### `postgres_driver.py`

Класс `PostgresDriver` отвечает за подключение и SQL-операции:

- `create_tables()` — создаёт таблицы идемпотентно через
  `CREATE TABLE IF NOT EXISTS`.
- `add_user(name, age)` — добавляет пользователя и возвращает созданную строку.
- `add_order(user_id, amount)` — добавляет заказ и возвращает созданную строку.
- `get_user_totals()` — возвращает ID, имя и сумму заказов каждого пользователя.
  Использует `LEFT JOIN`, поэтому пользователи без заказов также включаются
  с суммой `0.00`; результат сортируется по сумме по убыванию.
- `check_connection()` — выполняет `SELECT 1` для проверки соединения.

Соединение закрывается при выходе из блока `with PostgresDriver()`. Методы записи
используют транзакции. SQL-параметры передаются отдельно от запросов (`%s`).

### `seed.py`

Добавляет восемь тестовых имён. Каждому пользователю назначается возраст, который
ещё не использовался для этого имени; если исходный возраст уже занят, выбирается
другой свободный возраст от 18 до 100. Для каждого добавляются от 2 до 5 заказов
со случайными суммами. Данные вставляются в транзакции; при ошибке вставки
транзакция откатывается. После выполнения в консоль выводятся добавленные строки.

Повторный запуск добавляет записи снова. Имена остаются прежними, но возраст,
который уже использовался для конкретного имени, не выбирается повторно.

### `orders_summary.py`

Содержит функцию вывода итогов в формате `Имя — 1250.00`. Запуск отдельно:

```bash
.venv/bin/python orders_summary.py
```

### `test_postgres_connection.py`

Проверяет подключение к базе запросом `SELECT 1`. Запустить тест:

```bash
.venv/bin/python -m unittest -v test_postgres_connection
```

## Ошибки и диагностика

- **Не удаётся подключиться / неверный пароль / база недоступна.** Проверьте,
  что сервер PostgreSQL запущен, и значения `PGHOST`, `PGPORT`, `PGDATABASE`,
  `PGUSER` и пароль в `.env` правильные. Ошибки подключения PostgreSQL
  (`psycopg2.Error`) при старте приложения могут прервать программу с
  traceback.
- **`relation ... does not exist`.** Убедитесь, что создаёте и просматриваете
  таблицы в одной базе данных. В меню таблицы создаются при старте; либо выберите
  пункт «Создать таблицы». В pgAdmin проверьте базу из `PGDATABASE`, схему
  `public`, и обновите узел Tables.
- **Ошибка ограничений или внешнего ключа.** Возраст должен быть неотрицательным,
  а заказ должен ссылаться на существующий `users.id`. При ошибке вставки
  транзакция откатывается.
- **Исчерпаны доступные возраста.** Сидер остановится с `RuntimeError`, если
  для одного из тестовых имён все возраста от 18 до 100 уже заняты.
- **Неизвестный пункт меню.** Введите один из показанных номеров.
- **Ошибка при получении сводки из отдельного `orders_summary.py`.** Ошибка
  PostgreSQL выводится в `stderr`, процесс завершается с кодом `1`.
- **Сбой теста подключения.** Убедитесь, что тест запущен в терминале, где
  можно ввести пароль, либо задайте непустой `PGPASSWORD` в `.env`.

## Прямое использование драйвера

```python
from decimal import Decimal

from postgres_driver import PostgresDriver

with PostgresDriver() as db:
    db.create_tables()
    user = db.add_user("Тестовый пользователь", 30)
    db.add_order(user[0], Decimal("1250.00"))
    for user_id, name, total in db.get_user_totals():
        print(f"{name} — {total:.2f}")
```
